# Architecture

Next.js 16 + React 19 (RSC + Server Actions) on Vercel → Supabase (GoTrue auth, Postgres + RLS, Storage, Edge Functions). Reads via async Server Components (`@supabase/ssr` 0.7, `await cookies()`); mutations via Server Actions (Zod-validated, rate-limited, audit-logged); request interception in `proxy.ts` (Node runtime, session refresh only — never an auth boundary); storage direct-to-bucket with nightly orphan cleanup; `challenge-status` cron flips `upcoming→active→completed`; `send-email` (Resend) fires 12 lifecycle events. Search is Postgres full-text on `projects.search_vector` (v1 scope: projects only).
